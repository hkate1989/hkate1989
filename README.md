## Currently building

### [AutoBench](https://github.com/hkate1989/autobench)

An automated R&D loop for research agents: observe a failure, diagnose it, test a bounded intervention, and keep only improvements supported by measured results.

### [Mise](https://github.com/hkate1989/codex-playground)

A multimodal video-to-recipe MVP that turns authorized cooking videos into structured, timestamped recipes using transcription, sampled frames, and validated model output.
